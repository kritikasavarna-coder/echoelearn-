## 🧠 Overview

Most students read a topic once, feel like they've understood it, and then forget it within days. Echoelearn is built to break that cycle. You give it any topic, and it doesn't just explain — it actively pushes you to recall what you just learned and then tests you with a quiz, reinforcing the concept until it actually sticks.

---

## ✨ Features

- **AI-Powered Explanations** — Enter any topic and get a clear, structured explanation
- **Active Recall** — Follow-up questions that make you retrieve the concept from memory, not just re-read it
- **MCQ Quiz** — Test your understanding right after learning, for stronger long-term retention

*More features coming soon — this is an evolving v1.*

## 🛠️ Tech Stack

**Frontend:** React, Vite, JavaScript, JSX, HTML5, CSS3
**Backend:** Node.js, Express.js, REST APIs
**AI:** Google Gemini API
**Tooling:** Git, GitHub

---

## 🚀 Getting Started

```bash
# Clone the repository
git clone <repository-url>

# Install dependencies
cd frontend && npm install
cd ../backend && npm install

# Add your Gemini API key to backend/.env
GEMINI_API_KEY=your_api_key

# Start the backend
cd backend
npm run dev

# Start the frontend (new terminal)
cd frontend
npm run dev
```

Open **http://localhost:5173** in your browser.

---

## 📖 Usage

1. Enter any topic you want to learn
2. Read the AI-generated explanation
3. Answer the active recall questions
4. Take the MCQ quiz to lock in retention
